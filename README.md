# 📋 PHP Web Board

PHP와 MySQL을 활용하여 개발한 회원제 웹 게시판 프로젝트입니다.

웹 서비스의 기본적인 데이터 처리 과정과 CRUD 구조를 이해하기 위해 진행한 개인 프로젝트입니다.
회원가입 및 로그인 기능부터 게시글 작성, 조회, 수정, 삭제 기능을 구현했으며,
PHP Session을 활용하여 사용자의 로그인 상태를 관리했습니다.

또한 CSRF Token 검증과 사용자 권한 확인 기능을 적용하여
웹 서비스에서 발생할 수 있는 보안 문제를 고려하며 개발했습니다.

## ✨ 주요 기능

### 👤 회원 관리

- 회원가입
- 아이디 중복 확인
- 비밀번호 확인
- 사용자 정보 MySQL 저장
- 로그인 / 로그아웃
- PHP Session 기반 로그인 상태 관리


### 📝 게시판

- 게시글 작성
- 게시글 목록 조회
- 게시글 상세 조회
- 게시글 수정
- 게시글 삭제
- 게시글 조회수
- 페이지네이션


### 🔐 권한 관리

게시글을 작성한 사용자와 관리자를 구분하여
게시글 수정 및 삭제 권한을 처리했습니다.

로그인하지 않은 사용자의 게시글 작성 접근을 제한하고,
Session 정보를 활용하여 사용자 인증 상태를 확인하도록 구현했습니다.


### 🛡 Web Security

웹 보안을 고려하여 일부 요청에 대한 보안 기능을 구현했습니다.

- CSRF Token 생성
- CSRF Token 검증
- 사용자 입력값 Escape 처리
- Session 기반 사용자 인증
- 작성자 기반 게시글 수정/삭제 권한 확인

## 💡 프로젝트를 통해 학습한 내용

이 프로젝트를 개발하면서 웹 애플리케이션의 기본적인 동작 구조와
프론트엔드, 백엔드, 데이터베이스 간의 데이터 처리 과정을 학습했습니다.

특히 PHP와 MySQL을 직접 연동하면서 SQL을 활용한 데이터 조회 및 저장 방법과
CRUD 기능의 기본적인 구조를 경험했습니다.

또한 PHP Session을 이용한 사용자 인증과 CSRF Token 검증을 구현하면서
웹 서비스에서 사용자 인증 및 보안 처리가 필요한 이유를 학습했습니다.


## 🔧 개선 사항

초기 프로젝트에서는 사용자 비밀번호 저장 및 일부 데이터베이스 쿼리 처리 과정에서
보안상 개선이 필요한 부분이 존재했습니다.

이후 웹 보안에 대해 학습하면서 다음과 같은 개선 방향을 확인했습니다.

- 비밀번호 평문 저장 방식 개선
- bcrypt 등의 단방향 해시를 활용한 비밀번호 저장
- Prepared Statement를 활용한 SQL Injection 대응
- 데이터베이스 접속 정보 환경변수 분리
- 사용자 입력값 검증 강화

이러한 개선 사항은 이후 진행한 프로젝트에서 직접 적용하며
보다 안전한 웹 서비스 개발 방법을 학습하고 있습니다.
